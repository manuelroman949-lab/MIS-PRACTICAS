## 1. Objetivo de la Práctica
Desplegar un contenedor HTTPD (Apache) en Docker utilizando Kali Linux, personalizar la página de inicio `index.html` y verificar el correcto funcionamiento del servicio a través del navegador local y la terminal.

## 2. Información del Entorno
- **Sistema Operativo Host:** Kali Linux (VirtualBox)
- **Motor de Contenedores:** Docker
- **Imagen Utilizada:** httpd (Apache)
- **Nombre del Contenedor:** `mi_servidor_web`
- **Puerto Mapeado:** 8080 (Host) -> 80 (Contenedor)
