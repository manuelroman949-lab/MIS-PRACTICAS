# 🛡️ Laboratorio: Reconocimiento con Nmap Básico y Caza de Servicios Ocultos

Documentación oficial de la práctica de ciberseguridad orientada al inventario de red, análisis perimetral y detección de vectores de ataque mediante **Nmap**.

---

## 📋 Descripción General
Este laboratorio cubre los fundamentos del reconocimiento perimetral activo, diferenciando escaneos sigilosos frente a conexiones completas, análisis de versiones de software (Banner Grabbing), comportamiento de firewalls y la localización de servicios ocultos en puertos no estándar.

---
